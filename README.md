# SuperMimic 论文复现

本仓库整理 SuperMimic 论文的复现实验代码、环境配置、计划与报告。

- `cuboi_reproduction/`：以 CuboiLeo/SuperMimic-Reproduced e8 基线为基础的当前复现。
- `official_reference/`：论文作者实现的历史实验与 Spark 上的工程修改。`local-windows-changes.patch` 保存 Windows 副本的差异。
- `plans/`：两条路线的复现计划。

源码各自保留上游许可证与来源。此仓库保存源码快照，原有嵌套 Git 历史未随快照上传。数据集、模型检查点、运行视频和缓存未包含，请参照各目录 README 和报告获取。报告中的路径为实验时的历史路径。

当前状态请参考 `cuboi_reproduction/README.md` 与各报告；已有短训不代表论文结果或真机部署已复现。
