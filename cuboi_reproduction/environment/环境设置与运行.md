## 3. 原锁安装与隔离

安装临时容器使用host网络，以访问宿主已有回环代理；安装完成退出，`.venv`保留在项目挂载目录。研究和课程的Python包不共享。

```bash
docker run --rm --name supermimic-cuboi-setup --network host --gpus all \
  --user "$(id -u):$(id -g)" \
  --cpus 4 --memory 16g --memory-swap 16g --shm-size 1g \
  --env http_proxy --env https_proxy --env HTTP_PROXY --env HTTPS_PROXY \
  --env all_proxy --env ALL_PROXY \
  --env NO_PROXY=localhost,127.0.0.1,files.pythonhosted.org \
  --env no_proxy=localhost,127.0.0.1,files.pythonhosted.org \
  --env NVIDIA_DRIVER_CAPABILITIES=compute,utility,graphics \
  -v /home/nvidia/research/supermimic-cuboi:/workspace \
  supermimic-cuboi:py312 bash /workspace/environment/install_locked.sh
```

以上限定域名直连为实际发生大文件重试后的调整，原锁与缓存保留；对照证据见reports/P1_依赖下载路径诊断.md。最终安装输出在reports/P1_dependency_install_direct.log，原安装日志另保留。

4CPU/16GiB是此次首次检查设置，不是已测课程预留或长期训练上限。按后续实测调整并记录；容器限制不提供GPU算力硬隔离。

## 4. 正常运行容器

本次原安装发生大文件重试，后续采用原锁七项wheel独立下载和校验。先在Spark执行`python3 scripts/download_remaining_wheels.py`，成功生成wheelhouse-manifest.json后，在同一镜像临时容器执行`bash /workspace/environment/install_from_verified_wheels.sh`；它先按已校验清单安装本地包，再用原锁offline sync。其余已完成的uv缓存保留。详见下载路径诊断报告；不在校验尚未完成时执行该安装入口。

原锁安装成功后创建，桥接网络仅向宿主回环地址映射查看端口：

```bash
docker run -d --name supermimic-cuboi --gpus all \
  --user "$(id -u):$(id -g)" \
  --cpus 4 --memory 16g --memory-swap 16g --shm-size 1g \
  --env NVIDIA_DRIVER_CAPABILITIES=compute,utility,graphics \
  --env MUJOCO_GL=egl \
  -p 127.0.0.1:18080:8080 \
  -v /home/nvidia/research/supermimic-cuboi:/workspace \
  supermimic-cuboi:py312
docker exec -it supermimic-cuboi bash
```

已有容器用`docker start supermimic-cuboi`，不重复创建。端口已在首次实施前检查。停止研究作业不停止课程容器；`sleep infinity`容器本身不等于有训练运行。

## 5. 分层检查与测量

容器内源码根目录执行：

```bash
.venv/bin/python /workspace/scripts/check_environment.py
.venv/bin/python scripts/data/csv_to_npz_batch.py \
  --input-dir /workspace/data/raw/lafan1/g1 \
  --output-dir /workspace/data/processed/lafan1 \
  --input-fps 30 --output-fps 50 --workers 2
```

CUDA前后向、Warp实际kernel与NVIDIA EGL输出在`reports/P1_compute_render.json`，不以仅能导入依赖作为运行通过。

实际命令的资源测量：

```bash
.venv/bin/python /workspace/scripts/run_measured.py \
  --out /workspace/runs/实际实验名/metrics/resources.json \
  .venv/bin/python scripts/eval_benchmark.py \
  --ckpt /workspace/checkpoints/upstream/e8-boneseed-100k/e8_boneseed_ckpt_0100000.pt \
  --npz-dir /workspace/data/processed/lafan1 --clips walk1_subject1 \
  --num-envs 1 --out /workspace/runs/实际实验名/metrics/benchmark.json
```

调用前创建该实验metrics目录。测量为1秒采样，报告墙钟时间、子进程RSS峰值、采样容器内存峰值、宿主最小可用内存和整卡利用率。整卡/宿主指标包含其他任务；统一内存下RSS/cgroup不是完整GPU内存账目，也不能代替课程并行性能验收。
