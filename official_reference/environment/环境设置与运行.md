## 2. 设置顺序

以下在Spark执行；本机research目录保留Dockerfile、10_nvidia.json及验收脚本。

1. 建立独立目录，放置同级src/supermimic、src/mjlab_research及data/runs/reports/cache。
2. 将两个仓库固定到上述提交，在独立复现分支应用本次pyproject/uv.lock依赖补丁。
3. 从宿主 `/usr/share/glvnd/egl_vendor.d/10_nvidia.json` 复制NVIDIA EGL配置到Dockerfile旁，再构建独立镜像。该配置只有供应商库名，不含账户信息。
4. 创建4CPU/16GiB研究容器，挂载独立目录到/workspace；GPU设备0、工作目录/workspace/src/supermimic。根据本机实际网络设置研究进程代理，本次为宿主127.0.0.1:17897配合host网络，不改全局代理。
5. 在容器执行 `uv sync --python 3.13 --locked`。若从原作者锁开始，先保留原文件，应用审计中已验证的兼容约束及锁补丁。
6. 依次运行GPU、64环境物理、渲染和针对性测试。安装完成后的验收用 `uv run --no-sync`，避免验证命令再次修改环境。

当前容器的缓存配置通过exec环境变量生效；最新Dockerfile已包含后续镜像默认值。当前基础镜像与运行容器状态见reports；不要把“Dockerfile已更新”当作镜像已重建。

```bash
export MPLCONFIGDIR=/workspace/cache/matplotlib
export TRITON_CACHE_DIR=/workspace/cache/triton

uv run --no-sync python /workspace/check_gpu.py
```
